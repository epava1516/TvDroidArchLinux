# Fondo del inicio

`hero-home.png` es un recurso original generado para Arch TV con la herramienta
integrada `imagegen`. El prompt completo se conserva en `hero-home.prompt.txt`.
No contiene texto, marcas, personajes ni interfaz de Amazon. Se distribuye como
recurso del proyecto bajo su licencia MIT.

Se decodifica y ajusta a 1920×1080 fuera del hilo de entrada. La interfaz aplica
sombras y escala de presentación, conserva un fondo vectorial alternativo y
reutiliza el resultado por resolución. El PNG fuente se conserva sin alterar.
